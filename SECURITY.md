# Security model and guidance

Vedha drives real browsers against pages that may be hostile. Threat model for the current release (v0.1):

| Threat                                                                    | Mitigation                                                                                                                                                                                                                                                                                                                                                                    | Verified by                                                                                                                                                  | Known limits                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Page text tries to instruct the actor ("ignore previous instructions...") | Observations carry `untrusted: true`; the framework never interprets page text; actors receive it as data                                                                                                                                                                                                                                                                     | `integration.test.ts` "treats hostile page text as data"                                                                                                     | An LLM actor you plug in can still be manipulated; keep its tool permissions narrow                                                                                                                                                                                                                    |
| Navigation to / requests from disallowed domains                          | `allowedDomains` enforced for every request via Playwright `route`, **including every redirect hop** (GET/HEAD chains pre-validated; non-idempotent requests are never re-sent: the validated final response is served instead), WebSocket connections gated via `routeWebSocket`, service workers blocked in launched sessions, plus a sticky after-the-fact violation guard | tests "blocks a redirect to a disallowed host", "POST redirects, WebSockets, service workers"; found that a plain `route` handler does NOT see redirect hops | After an allowed POST redirect the page URL stays at the POST URL; `Session` over an existing page (`fromPage`) cannot block service workers (context already created); non-HTTP(S) transports, DNS rebinding and IP-literal tricks beyond hostname matching are not handled; Chromium only was tested |
| Dangerous URL schemes                                                     | Only http(s), about:, data: (data: blocked when a domain allowlist is set)                                                                                                                                                                                                                                                                                                    | `support.test.ts`                                                                                                                                            |                                                                                                                                                                                                                                                                                                        |
| Destructive actions                                                       | `destructive: true` steps are `blocked` unless policy `approveDestructive`                                                                                                                                                                                                                                                                                                    | `runner.test.ts`                                                                                                                                             | Spec authors must mark steps; nothing infers destructiveness                                                                                                                                                                                                                                           |
| Secrets in logs/bundles                                                   | Configured `secrets` and common token patterns are redacted from traces and bundles                                                                                                                                                                                                                                                                                           | `runner.test.ts`, `support.test.ts`                                                                                                                          | Pattern-based; unknown formats may leak; screenshots are not redacted                                                                                                                                                                                                                                  |
| Path traversal in outputs                                                 | `resolveInside` on every file written from user-supplied names                                                                                                                                                                                                                                                                                                                | `support.test.ts`                                                                                                                                            |                                                                                                                                                                                                                                                                                                        |
| Untrusted spec files                                                      | Strict zod validation, bounded sizes/timeouts                                                                                                                                                                                                                                                                                                                                 | `schema.test.ts`                                                                                                                                             |                                                                                                                                                                                                                                                                                                        |
| Resource exhaustion                                                       | `maxSteps`, `maxDurationMs`, `maxObservationChars`, per-action timeouts                                                                                                                                                                                                                                                                                                       | `runner.test.ts`                                                                                                                                             | No CPU/memory cgroup limits                                                                                                                                                                                                                                                                            |
| Running repository scripts                                                | The CLI never executes scripts from a target repository. Generated specs are only run by `promote --check` or `explore --check`, explicitly                                                                                                                                                                                                                                   | design                                                                                                                                                       | `--check` executes generated Playwright code on your machine; review it first                                                                                                                                                                                                                          |
| Sending data to external AI providers                                     | No provider is bundled or called; nothing leaves the machine by default                                                                                                                                                                                                                                                                                                       | design                                                                                                                                                       | An LLM actor you add decides what is sent                                                                                                                                                                                                                                                              |

Reporting: open a private security advisory on the repository once published. Do not include real credentials in reports.
