# Benchmark results: vedha-n20-frozen

Generated by `benchmarks/analysis/analyze.ts` from `benchmarks/results/vedha-n20-frozen/trials.jsonl`. Raw per-trial records are the source of truth.

* Trials: 1500 (15 scenarios × 5 drivers × 20 trials). Driver errors (harness-level): 0.
* Environment: darwin 24.6.0 x64, 8 CPUs (Apple M2), Node v22.20.0, Playwright 1.64.1, concurrency 4.
* git HEAD at run time: `unavailable`, working tree dirty: true.
* **All actors are scripted (no LLM).** Results measure framework semantics (verification, recovery, uncertainty handling), not model capability. See `methodology.md`.
* Intervals are 95% Wilson score intervals. With n=20 per cell, intervals are wide; a 20/20 cell has a lower bound of ~84%.
