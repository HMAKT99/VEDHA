## Cross-cutting observations
1. Compact observation is solved unevenly: AB has delta snapshots; PW offers only `full|none`.
2. Independent verification is largely absent from agent-facing layers; PW's `browser_verify_*` tools are explicit but caller-driven, and BU's judge is reported-only.
3. Recovery that can mask defects exists (SH `selfHeal`, healer's selector rewriting); none of the studied code visibly records "original failure + recovery" as a first-class pair. Verified for SH (`actService.ts:399-464`); *inferred* for others.
4. Exploration→deterministic test conversion exists in PW (`addCode`, generator spec); BU/SH replay artifacts are not test files.
5. Security postures differ widely; only AB documents fail-closed behaviour.
