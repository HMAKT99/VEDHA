# ADR-0006: First benchmark uses scripted actors, not an LLM

Status: accepted (forced by environment: no model API key configured). **Decision:** Phase 5 measures _framework semantics_ (verification, recovery, outcome_unknown, observation size, latency) with identical deterministic actors across drivers; LLM-driven results are explicitly out of scope until a key/budget is provided. Reports must say "scripted actor", never "agent success rate" for the LLM sense.
